EXECUTION-01: one completed evaluation drives reward backup and qid-prefix materialization.

The search tree uses relative paths; map each terminal path through a fixed
prefix embedding when the caller has a nonempty execution root. For the main
model below the full execution path is supplied explicitly by this embedding.
For each fixed panel qid, a completed path demands every nonempty execution
prefix. Resource identity is (qid, full prefix) within a fixed executor namespace.

An operational metered step updates the raw reward statistics with the same
completed event, adds previously absent demanded resources to the persistent
materialization set, and charges their fixed nonnegative physical weights.
Fresh evaluation/search/restore overhead is accumulated separately each time.
Derive the reward-history identity and cost conservation by induction on the
same event list. Prove the finite-resource cold budget and separate recurring
overhead, with no independence or restriction on how paths were chosen.

This is the successful, prefix-complete, persistent execution model. Current
restorable cache K and materialization ledger M may be identified only under
these conditions. Sparse checkpoint objects use the separate deepest-checkpoint
model; eviction, retries, changing executor identity, and failed partial panels
must not be smuggled into the once-only resource theorem.

Show qids are distinct in demand membership. A checkpoint for one qid never
removes another qid's resource. Replay of a materialized terminal path adds a
tree visit but zero new cold cost; recurring overhead remains payable.
