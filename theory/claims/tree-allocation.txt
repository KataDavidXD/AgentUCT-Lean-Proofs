ALLOCATION-01: bounded cost-perturbed UCT cannot indefinitely starve an initialized child.

The actual production index is Q + c*sqrt(log(N_parent+1)/N_child) - penalty.
The penalty already includes beta/C_ref. Use actual per-child visit counts from
the local action sequence. Q can change arbitrarily subject to [0,1]; penalties
can change arbitrarily subject to [0,H]. No confidence, drift, or stationarity
assumption is allowed in this claim.

Let parent count be local action count plus a fixed offset (zero at the root,
one for the birth rollout at a non-root node). On a window [L,U), assume all
children were initialized at L and each choice maximizes this actual index.
For an integer target m, require the explicit arithmetic conditions
  (H+2)^2*m < c^2*log(L+offset+1)
  K*(c^2*log(U+offset+1)+1) < U-L.
Prove every child has more than m visits by U.

Proof mechanism: a child still at count <=m has index >2. Any selected child
then has bonus >1 and therefore prior count <c^2*log(U+offset+1). Each child's
counts increase strictly when selected, so at most cap+1 such selections can
fit. Summing over K children contradicts the window length.

This is an algorithmic progress lemma, not the full tree regret theorem.
Derive explicit admissible windows, recursive tree coverage, subtree-deficit
rates and cost saturation separately before claiming a logarithmic guarantee.
