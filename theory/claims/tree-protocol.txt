TREE-01: operational expansion, completed-result commit, and best-training endpoint.

Paths in the model are relative to the caller's fixed root_path. Initially only
the empty relative path exists. One successful evaluation either reaches an
existing terminal tree node or adds exactly one child of an existing node. Its
terminal rollout extends that tree node. No rollout-only intermediate nodes are
inserted. Prove prefix closure and the one-node-per-completed-evaluation bound.
Each inserted node is an actual expanded path, not merely a rollout prefix.

Only a complete evaluator result is committed to tree reward statistics. An
incomplete result leaves the completed-event history and reward statistics
unchanged. This makes no claim that partial physical charges disappear; those
belong to the separate execution journal and cache model.

The best-training endpoint is the earliest strict improvement in observed
terminal Score. Prove membership and maximality over completed evaluations.
This does not establish the validation-shortlist endpoint or population quality.

Selection indices and valid terminal rewards will be constrained by subsequent
algorithm modules. TREE-01 alone neither enforces UCT choices nor proves regret.
